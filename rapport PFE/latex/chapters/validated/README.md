# Chapitres validés

Dossier vide pour l'instant. Workflow (cf. prompt maître §10) :

1. Un chapitre est rédigé et itéré dans `chapters/drafts/`.
2. Une fois relu (pédagogie, technique, sécurité, cohérence — grille de contrôle §26 du
   prompt maître) et validé par vous, déplacez le fichier ici.
3. Mettez à jour la ligne `\input{...}` correspondante dans `main.tex`
   (`chapters/drafts/chXX...` → `chapters/validated/chXX...`).

Un chapitre validé reste modifiable indépendamment des autres — le déplacer ne le fige pas
définitivement, cela signale juste qu'il n'est plus en itération active.
